# 購入済み商品一覧ページ UI/UX再構成案

## 目的
本サイトはDMM本体の検索機能が弱いことを補うための外部一覧ツールであり、
閲覧・ダウンロードは最終的にDMM側のページで行う。そのため本サイトの役割は
「大量のアイテムから目的の作品をすばやく見つけ、DMMのページへ橋渡しする」
ことに限定される。カード自体が`<a>`タグとしてDMMのページリンクを兼ねる
現行構成を維持し、「検索・絞り込み・並び替え」を強化するUI/UXを提案する。

## 対象の商品タイプ
デジタルデータ（電子書籍、ボイス、動画、CG集などの同人コンテンツ）

## 前提: 利用可能なデータ項目
取得できるデータは現状のJSON（`productId`, `title`, `circleName`, `genre`,
`pageLink`, `thumbnail`, `isFavorite`）のみとする。購入日時・ダウンロード期限・
更新有無・ファイル形式など、JSONに存在しない項目は「無い」ものとして扱い、
それらに依存する機能（新着順ソート、期限バッジ等）は提案から除外する。

なお`isFavorite`は抽出スクリプト実行時点のスナップショットであり、DMM側で
その後お気に入りを変更してもJSONは自動更新されない（動的に同期されない）。
そのためこの値を「現在のお気に入り状態」として信頼するのは不適切であり、
お気に入り機能はJSON側の値を無視し、本サイト独自のlocalStorage管理として
完結させる（詳細は3節参照）。

## 現在の要素・課題
- 現状: サムネイル・サークル名・ジャンル・タイトルのみのカードグリッド表示
- 実装済み: キーワード検索、ジャンル複数絞り込み（チェックボックスドロップダウン）、
  並び替え（タイトル/サークル名の昇順・降順）、状態のURLクエリ同期
- 課題:
  - お気に入り表示/絞り込み/切替のUIがない（JSONの`isFavorite`は同期されない
    スナップショットのため使わず、本サイト独自管理として実装する必要がある）
  - 件数が増えたときの表示継続手段（無限スクロール）がない

  ※「カード全体がリンクになっているだけ」は課題ではない。本サイトは検索・
  絞り込みの補助が目的で、閲覧・ダウンロードはDMM側で行うため、カード全体を
  クリックしてDMMのページへ遷移する現行のリンク構成をそのまま維持する。

## 1. 画面レイアウト構成案

```
┌─────────────────────────────────────────────┐
│ ヘッダー（タイトル）                          │
├─────────────────────────────────────────────┤
│ [検索ボックス] [ジャンル▾] [並び替え▾] [件数] │ ← 上部ツールバー（sticky）
├─────────────────────────────────────────────┤
│ [カード] [カード] [カード] [カード]           │
│ [カード] [カード] [カード] [カード]           │ ← 一覧グリッド
│ ...                                          │
│ （スクロールで自動的に続きを読み込み）         │ ← 無限スクロール
└─────────────────────────────────────────────┘
```

- ページ分割はせず、スクロールが下端付近に到達したら次のアイテム群を
  自動追加読み込みする（IntersectionObserverで末尾要素を監視する想定）
- 検索・絞り込み・並び替えの条件を変更した際は、表示件数をリセットして
  先頭から再度無限スクロールを開始する

- 上部ツールバーは画面幅に応じて折り返し、スマホでは縦積み（実装済みの
  レスポンシブ方針を踏襲）
- ツールバーは `position: sticky; top: 0;` でスクロール中も固定し、
  絞り込みをいつでも変更できるようにする

## 2. 検索・絞り込み・並び替えの具体案

### 検索
- 対象: タイトル、サークル名（実装済み）
- 追加候補: 商品ID（ユーザーが特定のIDで探すケース向け）

### 絞り込み（フィルター）
- ジャンル（複数選択、実装済み）
- お気に入りのみ表示（本サイト独自のlocalStorage管理による切替、要追加実装。
  JSONの`isFavorite`は使用しない）

### 並び替え
- タイトル順（50音/アルファベット、実装済み）
- サークル名順（実装済み）
- ジャンル順（同ジャンルをまとめて見たい場合向け）

デフォルトは現状どおりJSON記載順（デフォルト順）を維持する。

## 3. 1アイテムあたりの表示要素

```
┌───────────────────┐
│      サムネイル  [★]│  ← カード全体が<a>（クリックでDMMのページへ）
│                   │     ★のみクリック伝播を止めてトグル動作
├───────────────────┤
│ サークル名   [ジャンル] │
│ タイトル（省略表示）  │
└───────────────────┘
```

- カード全体は現行どおり`<a href="pageLink">`のまま維持し、クリックで
  DMMの商品ページへ遷移する（本サイトに独自の「開く」ボタンは設けない）
- **お気に入りトグル（★）**: カード右上などにオーバーレイ配置し、
  クリック時は`event.preventDefault()` / `stopPropagation()`でカードの
  リンク遷移をキャンセルしてトグルのみ行う
  - 保存先: ブラウザの`localStorage`のみ（本サイトはサーバーを持たない静的
    ページで、読み込んだJSONファイルへの書き戻しはできないため）
  - キーを`productId`、値をお気に入りON/OFFとして保存する。JSON側の
    `isFavorite`はDMM側と同期されないスナップショットに過ぎないため
    一切参照せず、表示・判定はlocalStorageの値のみで完結させる
  - 端末・ブラウザ単位のローカル保存となり、他端末とは同期されない点は許容する

## 実装への反映方針
- お気に入りフィルタ/トグルはJSONの`isFavorite`を使わず、localStorageのみで
  完結する機能として実装する
- 購入日時・ダウンロード期限・更新有無などJSONにない項目を前提にした機能
  （新着順ソート、期限バッジ等）は、データ項目自体が追加されない限り対象外とする
- 件数が増えた場合は無限スクロールで対応し、ページ分割は行わない
  （表示中の件数が多くなりすぎる場合は仮想スクロールの併用を検討）
